# Тарас Мюзик

Скіл клонування співаної реклами (song-VSL) українською мовою.

На вході — відео або mp3 конкурента зі співом. На виході — українська пісня того ж жанру,
темпу, тональності й структури, зі сценарієм рядок у рядок.

## Як влаштовано

| стадія | що робить |
|---|---|
| гейт бренда | питає назву бренду, продукту й склад до перекладу |
| 0 | паспорт ДНК еталона — темп, лад, LUFS, спектр, щільність складів |
| 1 | архетип сценарію: чому оригінал працює |
| 2 | текст українською за законом смислу |
| 3 | генерація, мінімум три заявки |
| 4 | відбір за замірами і построчною звіркою |
| 5 | доводка під спектр і гучність еталона |

## Два закони

**Закон нуля.** Спочатку точний транскрипт еталона. Якщо в кадр вшиті титри — вони і є джерело
правди, розпізнавання на слух вигадує цілі куплети.

**Закон смислу.** Рядок мусить донести думку цілком. Українська витрачає на ту саму думку
на 15–20 % більше складів, тому вимога складової рівні з англійською вирізає дієслова
й кінці фраз — і це чути як «співає про одне, потім про інше і не договорює».
